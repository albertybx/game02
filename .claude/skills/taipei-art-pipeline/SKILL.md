# 台北政壇大富翁：美術流程

這份 skill 是兩個來源整理出來的：
1. **這個專案自己試出來的經驗**（2026/11 視覺對話串，試了十幾輪才找到能用的做法）
2. 何佳勳 @chia.hsun301 在 Threads 的〈一個人做像素遊戲：13 個免費開源工具〉（2026/11/23 查證）。我們只取對這個專案有用的部分，並用自己的話改寫。

和通用的 `create-game-assets` skill 一起用：那份講一般原則，這份講這個專案的規格和做法。

---

## 一、最重要的三個教訓

| 做法 | 結果 | 結論 |
|---|---|---|
| Claude 或 Codex **寫 Python 程式一格一格畫像素圖** | 試了正面、側身、2 倍格數、誇張風、KING 風等版本，使用者都覺得「比現在的 AI 圖難看」「完全無法辨識」 | **不要再用程式畫角色或建築。**程式只拿來做後製（去背、縮放、拼預覽圖） |
| **Codex 用 `image_gen` 畫圖**，附上使用者喜歡的參考圖當風格 | 第一次就畫出使用者滿意的鷹九和中正紀念堂 | **畫圖一律請 Codex 用 image_gen** |
| 只看放大圖就下結論 | 放大很漂亮，縮到地圖上細節全部看不見 | **一定要縮到遊戲實際大小再判斷** |

另外，Threads 文章提醒的「素材全丟給 AI，比例和配色會對不起來」也是我們踩過的坑。解法是**先定好規格和參考圖，AI 畫草稿，人來挑、來修**。

## 二、使用者喜歡的風格（目前的定案方向）

- 像素風，方塊大而整齊，**黑色粗外框**，部位之間也有黑線
- 角色約 **2.5 頭身**：大圓頭、身體窄短、雙腳站穩
- 顏色少、大色塊，每種材質「本色＋一階陰影」，加一點亮光
- 臉簡單但有表情：粗眉、短橫線眼睛、腮紅、張開的嘴；**眼睛不能糊成一條黑線**
- 每個角色有一個招牌姿勢或道具，能看出他是誰
- 風格參考圖：使用者在 ChatGPT 請 GPT 畫的像素人物（雙手交握、光頭、白襯衫）。要用時請使用者再傳一次，或用這次畫好、他滿意的成品（例如鷹九晨跑揮手）當參考

**使用者不喜歡的**（不要再往這些方向走）：
- 很小、很簡化的 Q 版（30～40 格高），例如「奔跑吧！台北」或「Guess Who? My Heroes」那種小人
- 為了誇張而犧牲辨識度
- 半寫實、偏暗偏灰的配色

## 三、規格

### 地標建築（`assets/buildings/*.png`）
- 地圖是斜 45 度等角地圖，**一格地磚是 2:1 的菱形**（`src/game.js` 的 `ISO_W = 128`、`ISO_H = 64`）
- 建築的地基要剛好鋪滿這個菱形，牆、台階、屋簷都沿著菱形的兩條斜邊（約 26.6 度）
- 光從左上方來：左牆亮、右牆暗
- 原圖存成**寬 256** 的透明 PNG（現有建築都是 256 寬）
- 遊戲裡蓋好的地標縮成寬 `ISO_W - 6 = 122`（`refreshBuilding`），對齊方式是圖片底部中間＝菱形下方頂點

### 角色、戰將（`assets/characters/char*.png`、`assets/generals/gen*.png`）
- 透明 PNG，寬 200 左右（現有的是 200×300～400）
- 地圖上的棋子顯示約 **72 像素高**（`createTokens` 的 `addCharacter(..., 72)`）
- 大頭照是從原圖上方約 45% 裁切（`common.js` 的 `HEAD_CROP.ai`），所以**頭要在圖的上半部、臉不能被手擋住**
- 角色微側身、臉朝右前方，比較適合斜角地圖

## 三之一、風格切換（測試中）

- 網址加 `?style=2`、`?style=3` 會用新風格，程式在 `src/style.js`；首頁版本號旁會顯示「風格 N（測試）」
- 新圖放 `assets/style2/`、`assets/style3/`，**路徑和檔名跟原本一樣**（例如 `assets/style3/ground/iso_grass.png`），並加進 `STYLE_FILES`
- 地圖的顏色（海岸、各區草地、區界線、邊線粗細、樹的多寡和顏色）在 `MAP_STYLES`
- 使用者覺得「素材拼格子＋程式畫邊線」不自然，比較喜歡直接用 AI 畫好的整張概念圖當地面（風格 5 的做法）。拿整張圖當地面前，先把遊戲的道路、空地格子位置疊在圖上檢查對不對得上。
- 做新地圖風格的好方法：請 Codex 先用 image_gen 以原版地圖（`docs/images/地圖底圖-*.png`）為底畫整張概念圖，再拆成素材，並從概念圖取色寫成 palette.json
- 改完要確認原本的風格完全沒變：把河水和樹藏起來（每局隨機），比對改前改後的整張地圖

## 四、做一張新圖的流程

1. **確認要畫什麼**：角色或建築、特徵、招牌道具。讀 `src/data.js` 的資料，看目前的圖長怎樣。
2. **準備參考圖**，放在暫存資料夾的 `ref/`：
   - 風格參考（使用者喜歡的那張，或已定案的成品）
   - 目前遊戲裡的舊圖（保留特徵用）
   - 建築：用 `scripts/iso_guide.py` 做**透視底圖**，叫 Codex 當底圖編輯
     ```bash
     python3 .claude/skills/taipei-art-pipeline/scripts/iso_guide.py ref/iso_guide.png
     ```
3. **請 Codex 畫**（CLAUDE.md 有 Codex 的用法）。`TASK.md` 裡要寫：
   - 「**請用 image_gen 畫，不要用 Python 一格一格畫**」（不寫的話它會自己寫程式畫）
   - 上面第二節的風格描述，第三節的規格
   - 角色或建築的特徵
   - 純白背景、沒有文字、只有一個主體
   - 一次畫 2 張不同版本，存到 `out/`，自己檢查有沒有多手指、文字、背景不白、角度不對
   - `codex exec` 的 `-i` 會把後面所有參數都當成圖片，所以**指示要放在 `-i` 前面**，最後加 `< /dev/null`
4. **後製**：用 `scripts/cutout.py` 去背、裁切、縮成規格寬度，並產生遊戲大小的預覽
   ```bash
   python3 -I .claude/skills/taipei-art-pipeline/scripts/cutout.py out/gen_cks_2.png cks_new.png --width 256 --preview cks_preview.png --game-width 122
   ```
   去背是從四邊往內找連在一起的白色，所以建築裡的白牆不會被挖掉。邊緣如果有白邊，可以調 `--threshold`。
5. **給使用者看**：做一張「放大圖＋遊戲實際大小＋現在的版本」並排的比較圖。手機上看，字要用 `assets/fonts/Cubic_11.woff2`（PIL 讀不了 woff2，要先用 fontTools 轉成 ttf）。
6. **使用者選定後才放進遊戲**：換掉 `assets/` 裡的檔案（檔名不變就不用改程式），照 CLAUDE.md 改 `GAME_VERSION`、用 iPhone 13 和 1440×860 截圖測試、開 PR 合併。
7. **記錄來源**：在 `assets/ASSETS.md` 寫一行（見第六節）。

**一致性**：新風格的圖跟舊 AI 圖放在一起會很不搭。換圖最好**一類一次換完**（例如全部地標），或先換 2～3 張確認整套搭得起來再全部換。

## 五、Threads 文章的 13 個工具：我們用不用得到

文章把工具分成三層加上 AI。我們用的是 **Phaser 網頁遊戲**，地圖是程式畫的，所以大部分引擎和地圖工具都用不到。

| 層 | 工具（授權） | 用途 | 這個專案 |
|---|---|---|---|
| 素材 | **pixelfx**（MIT，GitHub `patch-gg/pixelfx`） | 244 種像素特效（火焰、爆炸、冰、閃電、天氣、撿東西、傳送…），每種是一小段程式，可換調色盤，匯出 PNG＋JSON 精靈圖 | **值得試**。Phaser 能讀 PNG＋JSON 的動畫圖集，可以拿來做當選煙火、拔樁戰爆炸、紅包飛出來這類特效。很新（2026/10 底建立），匯出要 Node.js（雲端有）。用之前先看 repo 說明確認匯出格式 |
| 素材 | Piskel（Apache-2.0） | 網頁版像素畫軟體，不用安裝 | 使用者想**自己小修圖**時推薦這個，打開網頁就能用 |
| 素材 | Pixelorama（MIT） | 功能完整的像素畫軟體，有網頁版 | 要做角色動畫、逐格修圖時可用 |
| 素材 | LibreSprite（GPL-2.0） | Aseprite 舊版分支 | 用不到（Piskel 就夠） |
| 組裝 | Godot、Pyxel、TIC-80、raylib | 遊戲引擎 | 用不到，我們是 Phaser |
| 組裝 | Tiled、LDtk | 地圖編輯器 | 用不到，地圖在 `src/data.js` 用程式產生 |
| 打光 | Laigter（GPL-3.0） | 從精靈圖自動做法線貼圖，讓 2D 圖有立體打光 | 目前用不到。之後想做「白天變夜晚」，Phaser 也有 Light2D 可以搭配法線貼圖 |
| AI | aseprite-ai-artist（MIT） | 讓 Claude Code、Codex 在 Aseprite 裡一格一格畫 | 用不到：要付費的 Aseprite，又要在使用者電腦上開著。而且「AI 一格一格畫」正是我們試過效果不好的做法 |
| AI | Sprite Sage（GPL-3.0） | Windows 版 AI 生角色、調動畫 | 用不到：只有 Windows，雲端生成要自己的金鑰並付費 |

**Aseprite（付費）**：Steam 台灣區售價約 NT$377。原始碼雖然公開，但自己編譯只能個人用、不能散布。

## 六、授權和來源紀錄

文章的提醒，我們照著做：
- **每一張素材都記一行來源和授權**，記在 `assets/ASSETS.md`：檔名、誰做的（哪個 AI、哪個工具、還是使用者自己）、日期、授權或使用條款
- AI 生成的圖，正式上架（例如 Steam）前要再對一次各 AI 服務的使用條款；Steam 的送審問卷要說明哪些內容是 AI 生成的
- 使用者給的風格參考圖（別人的作品）**只拿來學風格**，不能放進遊戲，也不能照抄裡面的角色、標誌、配色組合
- 不畫受版權保護的角色（超級英雄、卡通人物等）

## 七、政治諷刺的分寸

- 遊戲角色都用虛構名字（`src/data.js`）。有些戰將會讓人聯想到真實人物（三位前總統、前市長），畫的時候：
  - 笑點放在**行為、職業、招牌習慣**（晨跑、搶麥克風、發紅包），不拿長相或身體缺陷開玩笑
  - **各陣營誇張的程度要一樣**，不要只酸某一邊
  - 表情保持溫和友善，不要醜化
