# 台北政壇大富翁｜30 回合現金流與平衡建議

- 每位玩家有 $2,000 開局金。買地先用掉大筆現金，後半場還要持續繳租金和里長經營費。
- 最缺錢的是選前衝刺。起點每次只發 $300，玩家有時等不到下次領錢，就得放棄地盤或半價賣地。
- 優先做三項：定期小額政治獻金、調高起點獎金、降低高階過路費和里長經營費。
- 募款餐會、戰將黑金等玩法可在第一波調整後逐項試玩，避免一次加太多現金。

## 現在的錢怎麼進出

以下金額都是遊戲幣。買地、養地和過路費是三筆不同的帳：買地付一次，養地每回合或隔幾回合付給銀行，過路費則由踩到的對手付給地主。

| 收入 | 現行規則 |
|---|---|
| 開局金、起點 | 一人 $2,000。向前經過或停在起點時 +$300。卡片叫你往前去起點、捷運或塞車格，途中跨過起點也會領。後退經過起點沒有獎金。 |
| 地產過路費 | 對手**停在**你的地產時付給你。基本費是地價 ÷ 10 四捨五入，再按 0～3 級乘以 1／3／7／14。拿下整區時，0 級空地加倍。夜市商圈完工地標再乘 1.5。 |
| 里長過路費 | 對手停在你的里長格時付里長標價的 10%，即 $8～$14。 |
| 交通樞紐 | 每個完工的交通樞紐在自己回合開始時 +$50，先入帳再收養地費。 |
| 機會卡、命運卡 | 機會卡的小額捐款 +$150、通告費 +$100，另有一張讓每個未破產對手各付你 $30。命運卡的迷因聲量 +$50。牌組為全桌共用，抽完才洗回。 |
| 免費加蓋卡 | 機會牌組 18 張中有 6 張。能蓋就免費升一級，省 $50～$150，現金不變。如果沒有可升級的自有地產，改領 $100。 |
| 英文挑戰 | 選配。開啟後用 3 格英文挑戰替換 1 格機會和 2 格命運。答對 +$200 及 80 支持者，答錯扣 50 支持者。電腦答對率 60%，每次踩中平均值 $120。 |
| 任務退款 | 派戰將拉攏里長後，結算時該格已有主人就退回這趟的預付款。先前自己付的拜訪費仍是另外一筆。 |
| 被迫變賣 | 過路費或罰款等強制付款付不出來時，從半價最便宜的地盤開始賣。每格回收 `（標價＋級數 × 單次升級價）÷ 2`，四捨五入。里長格也能賣，免費升的級數照算。賣光仍不足就破產退出，收款人只拿到實際付出的金額。 |

| 支出 | 現行規則 |
|---|---|
| 買地、升級 | 空地 $100～$300。停在或往前經過自己的地可以加蓋，每級地價的一半，從買地到完工總價 $250～$750，免費升級可抵掉其中一級。 |
| 地產租金 | 每回合開始付給銀行，金額為 `地價 × 1% ×（級數＋1）`，四捨五入。空地也收，每格 $1～$3，完工每格 $4～$12。貴的先付，付不起的格子直接失去，沒有回收款。 |
| 拜訪、拉攏里長 | 親自拜訪 2 次，每次 $40～$70。也可派戰將去空的里長格，拜訪過就預付剩下半價並等 2 回合，從未拜訪則預付全價 $80～$140 並等 3 回合。小傑少等 1 回合，至少等 1 回合。 |
| 里長經營費 | 自取得或拔樁成功的回合起，每持有滿 3 回合付標價的 40%，每位 $32～$56。先於地產租金收，付不起就失去里長。同一玩家在同區有政府機關地標時免收。 |
| 戰將招募、挖角 | 招募 $300，挖角忠誠度低於 60 的對手戰將，成功才付 $400 給銀行。前東家不會收到錢。 |
| 戰將任務 | 跑紅白帖和選民服務免費。媒體宣傳 $100，林語辰免費。三種任務回來都帶支持者，選民服務還能穩固樁腳。文化地標、家鄉和能力加成影響任務效果，沒有任務獎金。駐守免費。拔樁也免費，但要先付該里長格的過路費。 |
| 造勢晚會、辯論 | 擲骰前可花 $150 換 200 基礎支持者，每場最多 2 次。第 16 回合起，落後領先者至少 600 支持者可花 $100 辯論，每人每場 1 次，輸贏都要付，結果是支持者倒戈。 |
| 對手地盤、對手的卡 | 停在對手格就付過路費。對手抽到指定機會卡時，你另付 $30。這兩種是玩家互付。 |
| 拖吊、卡片費用 | 拖吊 $100。機會卡園遊會 $100。命運卡有公關費 $100、違停 $50、重做看板 $80、雨天晚會 $80、總部水電費每個已蓋級數 $25（全地圖自己的地產加總）。 |

塞車暫停一次移動，回合開始的租金、經營費、任務結算和交通樞紐照常。捷運站本身免費。整區加成、觀光人潮、香火鼎盛、一般任務與戰將醜聞主要改變支持者或戰將狀態。30 回合局的第 21～30 回合，支持者增減倍率從 1.1 倍升到 2 倍，現金獎勵和費用照原價。投票比較支持者，沒有選票兌現金的結算獎金。只剩一位未破產時會提前結束。

## 怎麼估算

[模擬器](sim/economy.cjs) 在 Node.js 讀取現有規則和流程，用固定亂數種子重跑。每組 1,500 局、每局 4 人、設定 30 回合。四個座位都採遊戲內建電腦決策，會依前方地盤在 1 或 2 顆骰子之間選擇，買地後保留至少 $200、加蓋後至少 $400。實際人類可選擇不同的花錢方式，預設擲兩顆。本估算適合比較規則，真人場的金額與時間仍會不同。畫面操作用自動選擇取代，防守戰將的風格在模擬中隨機選。英文模式中四人都以 60% 答對率計算。

現金與事件以每局原始 4 個座位平均，破產者往後以 $0 計，提前結束沿用結局餘額。支出以實付為準，半價變賣列在收入欄方便對帳，屬於把資產換回現金。免費升級無現金流。各欄四捨五入後可能有尾差。

### 哪一段最缺錢

| 回合結束 | 平均現金 | 手上低於 $200 的座位 |

| 第 10 回合 | $1,065 | 0.23% |
| 第 15 回合 | $736 | 4.20% |
| 第 16 回合 | $574 | 8.08% |
| 第 20 回合 | $333 | 28.90% |
| 第 25 回合 | $207 | 53.52% |
| 第 26 回合 | $200 | **54.75%** |
| 第 28 回合 | **$197** | 52.62% |
| 第 30 回合 | $198 | 51.50% |

- **前半場把現金換成地盤。** 單是買地平均就用掉 $1,058，超過一半的開局金。持有地盤會持續帶支持者，初期買地很合理，但短期的現金回收慢。
- **第 16 回合開始明顯變緊。** 模擬平均一回合少了 $162。這是電腦開始願意辦造勢、也開放辯論的第一回合，原有的租金和里長費繼續扣。兩種養地費合計每局平均 $487，接近起點總收入 $576。
- **第 24～28 回合最吃緊。** 第 26 回合低於 $200 的比例最高，第 28 回合平均現金最低。兩顆骰子的純移動估算一圈約 11 次擲骰，電腦有時只擲一顆，塞車也會拉長領錢間隔。信義區的 $300 地產完工後一次收 $420，相當於 1.4 次起點獎金。此時又進入支持者增減加倍的末段，丟地會同時削弱後續拉票能力。
- 平均每 100 個原始座位，整局出現約 **61 格半價變賣、291 格因繳不起養地費直接失去，9.3 人破產**。同一人可失去多格。里長第 3、6、9…個持有回合若剛好撞在同一輪，會先扣里長費，再扣地產租金，等到擲骰時才有機會從起點領錢。

## 7 個新增賺錢機制

以下都是遊戲內事件。每人、每局的上限以 30 回合為基準，先用相同上限測 50／80 回合，再看各模式的現金是否需要分開調整。

| 點子 | 怎麼觸發與金額 | 代價、風險與上限 | 手機操作 |
|---|---|---|---|
| **1. 小額政治獻金** | 第 5、10、15、20、25 回合，未破產者在自己回合一開始自動領 $100，塞車也照領。 | 每場最多 $500，所有座位同額、不看支持者或地盤。第 5 回合才開始，留住開局選地的取捨。 | 自動入帳，銀行圖示旁顯示「小額獻金 +$100」。 |
| **2. 募款餐會** | 第 8～25 回合，擲骰前可花 $60 訂席，下個自己回合開場收 $220。 | 淨賺 $160，需先付錢且等一回合。和造勢共用每局 2 次活動額度，辦餐會就少一次買支持者的機會。當場破產時未結算款項取消。 | 行動選單一顆「募款餐會」，按鈕直接寫「現在 −$60／下回合 +$220」。 |
| **3. 戰將黑金門路** | 第 8～25 回合，派 1 位待命、人脈至少 4 的戰將離隊 2 回合。回來時 65% 入帳 $400，35% 遭到遊戲內調查、收入 $0、失去 350 基礎支持者並扣 15 忠誠。 | 每隊每局一次，期望入帳 $260，代價是戰將暫時無法出任務或拔樁。調查扣分照結算時選前倍率放大，屬於這個行動的固定風險。 | 戰將行動一鍵派出，自動選人脈最高的合格戰將，確認畫面同時顯示 65%／35% 和兩種結果。 |

## 舊數字 → 新數字

| 現有設定 | 目前 → 建議 | 理由 |
|---|---|---|
| 起點獎金 `passGoBonus` | $300 → **$400** | 平均約領兩次，直覺、免多按按鈕。增加移動回報，讓想保留現金的人有機會等到下一圈。 |
| 地產過路費倍數 `rentMultiplier` | 1／3／7／14 → **1／3／6／10** | 保留前兩階段的收入。信義 $300 地產完工收費由 $420 降到 $300，仍有明顯的完工回報。夜市仍乘 1.5，例如 $200 的饒河夜市由 $420 降到 $300。 |
| 里長經營費 `chiefFeeRate` | 40% → **30%**，維持每 3 回合 | 每位一次由 $32～$56 降到 $24～$42，減少同回合多位里長扣款時失去地盤的情況。 |
| 戰將招募費 `recruitCost` | $300 → **$250**（第二波備選） | 每次少付 $50，有機會讓想試戰將系統的玩家更早招到第一位。第一波先保留 $300，避免新收入和招募折扣一起推高戰將數量。 |

## 最優先做的 3 項

1. **定期小額政治獻金。** 用每 5 回合一次的自動入帳把錢送到玩家手上，尤其第 15、20、25 回合能接住下半場支出。先於養地費發放。
2. **起點 $300 → $400。** 改一個現有數字，保留繞完一圈領補給的節奏。
3. **一起調低高階過路費與里長費。** 過路費調到 1／3／6／10，里長費調到 30%。前者減少單筆大額付款，後者減少回合一開始就掉地盤。

模擬把這三項合在一起試跑。其餘點子與招募降價尚未放入試跑。

| 30 回合、4 人 | 現行 | 三項一起試跑 |
|---|---:|---:|
| 第 20 回合平均現金 | $333 | $597 |
| 第 25 回合低於 $200 | 53.52% | 19.07% |
| 第 30 回合平均現金 | $198 | $335 |
| 第 30 回合低於 $200 | 51.50% | 31.78% |
| 每 100 個座位全局半價變賣格數 | 61 | 32 |
| 每 100 個座位全局欠養地費失去格數 | 291 | 145 |
| 破產座位比例 | 9.3% | 1.2% |

試跑中玩家拿到錢也更願意投資，平均付費加蓋支出由 $129 增至 $252。即使單次里長費打折，整局實付也由 $227 升至 $277，因為玩家能養更多里長、養更久。第一波上線前，真人試玩可看第 20～30 回合是否仍常因缺錢跳過想做的事，以及領先者是否把新增資金大量換成地盤。若現金仍不足，優先加測募款餐會，讓玩家可以用一次造勢機會換回現金。
