# 三位角色試畫

- **阿芳姐**擅長打聽市場消息，讓她一手攏在嘴邊喊話，一手把裝滿青菜的大菜籃往前送。低而寬的輪廓很好認。
- **蔡大嘴**靠開講搶鏡，讓他張嘴搶話，把麥克風舉到比頭還高。麥克風和跨開的站姿讓他在棋盤上很醒目。
- **莉莉**靠國手魅力助選，讓她側身跨步，把大獎牌遞到觀眾眼前。緞帶垂出一個大圈，像是隨著動作甩出去。

剪影自測時，阿芳姐的菜籃最容易認。蔡大嘴和莉莉原本都有高舉道具的姿勢，後來把莉莉的獎牌往前移，讓緞帶下方留空，兩人就能靠直立的麥克風和橫伸的手臂分辨。只看黑影時，獎牌上的細節仍要靠彩色版補足。

我最滿意阿芳姐，菜籃縮到棋盤上依然讀得到。莉莉的動作有辨識度，但手機寬度的預覽裡，獎牌上的「1」已經很難看清。棋盤試貼沿用原截圖的彈窗和暗底，三人各以 72 像素高貼在露出的格子上。
