# 金水伯雙倍格數試畫

站姿和跑姿都用 96×128 的格子重畫，各用了 26 色（透明不計）。灰髮多了分層和成束的亮面，瞇眼旁加了笑紋，牙齒也有短分線。襯衫畫出了翻領、門襟和扣子，紅背心加了口袋和縫線，褲腳與皮鞋補了摺痕和亮光。佛珠有一顆顆的輪廓和亮點。

並排同尺寸放大看，最容易看出差別的是佛珠、頭髮和衣服。試著縮回 48×64 後，笑臉、紅背心和跑步剪影仍然清楚，牙齒分線、縫線和單顆佛珠的亮點就很難辨認。手機地圖如果只給角色這麼大的顯示空間，差別會比較小。角色能顯示得更大時，這些細節才有空間看清楚。

寬高加倍後，每格動畫有四倍的像素格。畫面還是可以用大色塊處理，工時不會直接按格數乘四。若要保留這版的細節，我估計描繪和逐格修整約需原本的 1.5–2 倍時間，實際還得做完一組動畫才知道。
