# 台北政壇大富翁（8-bit 像素風）

一款以台北地標為地圖、政治人物為角色的大富翁小遊戲。用 [Phaser 4](https://phaser.io/) 做的網頁遊戲，手機瀏覽器就能玩。

## 怎麼玩

- 首頁可以選：2～4 位候選人、「我 vs 電腦」或「朋友輪流玩」（同一支手機輪流按）、回合數（30／50／80）、要不要加入「英文挑戰」和測驗程度（國小／國中／高中／大學）。
- 地圖照**真實台北市行政區圖**做（中間的區放大一點），一圈 78 格，經過 12 個行政區；每區有 3 塊空地和 1 個里長，草地顏色不同、區界有白線。另外有機會、命運、5 個戰將招募站、起點、塞車、捷運站、拖吊場。擲 1 或 2 顆骰子（點骰子切換），照角色腳下的箭頭方向走；停在捷運站可以搭到另一站，下車後方向隨機。
- **空地慢慢蓋成地標**：空地 → 工地 → 小建築 → 地標，完工時隨機抽這一區的地標（每區 3 種，共 36 種），每個地標有特殊效果（觀光人潮、夜市商圈、香火鼎盛、政府機關、文化地標、交通樞紐）。
- 每個人有**錢**和**支持者**兩種數值。錢用來買地、蓋房子、付過路費；**支持者決定誰當選**。
- **里長**（比較便宜，主要拉支持者）：拉攏里長支持者 + 200，過路費很低，不能蓋房子。
- **每回合開始**：自己的空地／地標和里長會帶來支持者（空地：價錢×0.15×（階段+1）；里長：每位 50）。
- **對手踩到你的地**：除了付過路費，還會有一部分支持者倒戈到你這邊（空地：價錢×0.2×（階段+1）；里長：80）。
- 拿下同一區的全部空地和里長，那一區還沒蓋的空地過路費加倍，還有整區加成。
- 機會／命運卡：政見發表會、被爆料、名人站台、失言被罵翻……會影響錢或支持者。
- **起點錯開**：每位玩家往前多站 2 格，先擲骰的人才不會太佔便宜。
- **蓋房子**：停在或經過自己的空地時可以付錢加蓋；機會卡有 6 張「免費加蓋一個階段」。畫面中央的事件框只在機會／命運和戰將成果時出現，其他訊息看下方訊息列和「紀錄」。
- **擲骰子前的行動**：造勢晚會（花錢換支持者，每場 2 次）、遠端派戰將出任務、派戰將去拉攏里長、辯論挑戰（下半場落後第一名很多時）、神秘的金援（派戰將找金主，有風險）、企業贊助（有地標才能接）、賣地換現金。
- **賺錢**：經過起點 $400；每 5 回合有里長的人領政治獻金；比賽過一半發選舉補助款；每 6 回合完工地標依種類有營收；在里長格可以派戰將辦募款餐會、接政府標案。
- **租金與經營費**：地標每回合付租金，里長每 3 回合付經營費，付不出來就失去那一格；錢不夠付過路費時，先半價變賣地盤才破產。
- **里長要拜訪 2 次**才拉攏得到（第二次也可以派戰將去）。
- **選前衝刺**：最後 10 回合支持者的增減一回合比一回合大（最後一回合 ×2）。
- **整區加成**：同一區（2 格以上）全部拿下，每回合多 100 位支持者。地圖上有行政區看板。
- **戰將招募站**：翻 2 張戰將卡挑 1 位（$300），人數沒有上限；也能挖角對手忠誠度低於 60 的戰將。
- **戰將**有口才、人脈、魅力三項能力和一個專屬技能。派任務會離開隊伍 1～3 回合（跑紅白帖／選民服務／媒體宣傳／募款餐會／政府標案）；站在自己的里長格可以讓他駐守（駐守後離隊）；在對手的里長格可以「拔樁」：三戰兩勝的出招互剋（演講剋造勢、造勢剋拜訪、拜訪剋演講）加骰子，用三張牌出招、骰子動畫和大字分數，出戰前會顯示勝算，樁腳越老越穩。
- 戰將有忠誠度，命運卡可能出現「戰將醜聞」。目前戰將是虛構人物，名單在 `src/data.js` 的 `GENERALS`，可以換。
- 英文挑戰格（首頁選擇加入時才有，共 3 格）：隨機出英文選擇題或填空題，單字和句型都有。答對：錢 + $200、支持者 + 80；答錯：支持者 - 50。
- 最後一回合結束是「投票日」，**支持者最多的人當選**（一樣多再比總資產）。錢燒光就退出選戰。投票日畫面可以打開「選戰趨勢報告」，回顧整場選戰的民調走勢。
- 斜 45 度的畫面，鏡頭會跟著角色走；可以拖曳移動地圖，點玩家卡片會跳到那個角色。
- 放大縮小：右上角的 ＋／－ 按鈕；手機可以兩指縮放，電腦可以用滑鼠滾輪。
- 背景音樂：原創 8-bit 音樂（標題、遊戲中、當選三首）。打開網頁先出現「點一下開始」，點完音樂就開始；右上角 ♪ 可以關掉。
- 手機直拿是直版畫面；電腦或平板橫放會自動換成寬螢幕版面（左邊玩家資訊、下方訊息）。
- 點地圖上的建築可以看價錢、地主、過路費、每回合帶來多少支持者。
- **人數統計**：用 Google Analytics 記錄瀏覽人數，以及「開始選戰」「玩完一場」次數。
- **加到主畫面當 App**：iPhone Safari「分享 → 加入主畫面」、Android Chrome「加到主畫面／安裝」，之後從桌面圖示全螢幕打開。
- **勢力圖**：遊戲中右上角「勢力」按鈕，看 12 區各被誰佔了幾格、誰整區制霸。
- **選角色**：首頁點角色可以從 4 位政治人物和 12 位戰將裡挑（選了戰將，那位戰將就不會出現在招募站）。
- 畫面上有「即時民調」長條圖、目前所在格子的名稱，以及「選戰指南」按鈕（所有格子的效果說明）。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 遊戲網頁入口 |
| `src/data.js` | **想改內容先看這裡**：地圖格子、價錢、角色名字、機會/命運卡、規則數字 |
| `src/pixelart.js` | 像素圖（16x16 的文字格子，一個字母是一個顏色） |
| `src/game.js` | 斜 45 度城市地圖、角色移動、遊戲規則（買地、付錢、卡片、結算） |
| `src/hud.js` | 疊在地圖上的介面：玩家資訊、骰子、訊息、按鈕、卡片、結算畫面 |
| `src/title.js` | 標題畫面（選人數、模式） |
| `src/quiz.js` | 英文挑戰：題庫（`QUIZ_BANK`，四個程度）和答題視窗，想加題目照格式往下加 |
| `src/report.js` | 投票日的「選戰趨勢變化報告」：民調走勢折線圖、重點數字、每回合數據表 |
| `src/generals.js` | 戰將系統：招募、挖角、派任務、駐守、拔樁戰（出招互剋＋骰子、勝算計算）、忠誠度、醜聞 |
| `src/guide.js` | 「選戰指南」視窗的內容（數字直接讀 `data.js` 的規則） |
| `src/common.js` | 共用工具：8-bit 音效、像素按鈕 |
| `src/music.js` | 8-bit 背景音樂：樂譜（`SONGS`）和即時演奏的合成器，想改旋律改樂譜就好 |
| `src/boot.js` | 啟動遊戲 |
| `assets/buildings/` | （之後放 AI 畫的建築圖，在 `src/data.js` 的 `BUILDING_IMAGES` 登記） |
| `assets/generals/` | 12 位戰將的 Q 版像素圖（Codex 生成） |
| `assets/buildings/` 裡的地標 | 36 種地標、工地、小建築（Codex 生成），在 `src/data.js` 的 `LANDMARKS` 登記 |
| `assets/cards/` | 拔樁戰的三張出招牌（演講、拜訪、造勢，Codex 生成） |
| `lib/phaser.min.js` | Phaser 4.2.1 遊戲引擎（MIT 授權） |
| `assets/fonts/` | 俐方體 11 號像素字型（SIL OFL 授權） |

## 在電腦上執行

在專案資料夾執行 `python3 -m http.server 8000`，再用瀏覽器打開 <http://localhost:8000>。

# 關於這個範本（game-starter）

我的遊戲專案範本。在 GitHub 上按 **Use this template** 建立新的遊戲 repo，新的 repo 會自帶下面這些遊戲開發 skill。在雲端 session 或桌機版 Claude Code 中打開專案，Claude 就會自動讀到。

## 裡面有什麼

`.claude/skills/` 裡放了 **77 個遊戲開發 skill + 1 個 router**：

| 類別 | 數量 | 內容 |
|---|---|---|
| 遊戲引擎 | 49 | Godot 16、Unity 8、Unreal 6、網頁（Phaser / PixiJS / three.js）6、Roblox 8、Bevy / Defold / LÖVE / pygame 4、Ebitengine 1 |
| 系統與手感 | 15 | 打擊感、存檔、對話、鏡頭、隨機生成、敵人 AI、關卡設計、效能… |
| 遊戲類型 | 9 | 平台跳躍、Roguelike、RPG、FPS、塔防、卡牌、視覺小說、生存製作、解謎 |
| 上架流程 | 4 | Game Jam、快速做原型、Steam、itch.io |
| router | 1 | 依照你用的引擎和需求，自動挑出要讀哪幾份 skill |

不用指定 skill，直接用中文說需求就好，例如「幫我的角色加二段跳」。

## 新遊戲怎麼開

1. 在這個 repo 的頁面按 **Use this template → Create a new repository**
2. 幫新遊戲取名字，例如 `my-first-game`，按建立
3. 用新的 repo 開一個 Claude 雲端 session，或 clone 到桌機，然後開始做遊戲
